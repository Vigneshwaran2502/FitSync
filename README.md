# FitSync 🏋️‍♂️

## Overview
FitSync is a premium, state-of-the-art gym management and membership platform. It provides a beautiful, modern interface for gym members to manage their subscriptions, track fitness progress, and request services like membership freezing. The platform also serves Administrators and Trainers to manage users, workouts, and facility attendance.

## Features
* **Modern Aesthetic UI:** Built with React, TailwindCSS, and sleek micro-animations for a highly engaging user experience.
* **Authentication & Authorization:** Secure JWT-based login with role-based access control (Members vs. Admin/Trainer).
* **Membership Management:** Users can subscribe to tiers (Basic, Standard, Premium), renew plans, and request to freeze their accounts.
* **Simulated Checkout:** A beautiful, fully custom "Simulated Razorpay" payment popup for easy testing and demonstrations.
* **Workout & Progress Tracking:** Trainers can assign routines; members can log their fitness goals and metrics.
* **GPS & QR Attendance:** Verify your daily gym session via rolling QR code or GPS geofence (Haversine formula).
* **AI Coach:** Gemini-powered AI chatbot for fitness queries.
* **REST API Backend:** A scalable Node.js/Express backend connected to MongoDB.

## Tech Stack
* **Frontend:** React.js, Vite, Tailwind CSS, Motion (framer-motion), Recharts, React Hook Form, Zod.
* **Backend:** Node.js, Express.js, MongoDB (Mongoose), JWT, node-cron.
* **AI:** Google Gemini API.

## Project Structure
The project is cleanly divided into two independent directories:
* `/frontend` - React + Vite frontend application.
* `/backend` - Node.js + Express backend server.

## Prerequisites
* Node.js (v18 or higher)
* MongoDB (or a MongoDB Atlas connection string)
* API Keys for Google Gemini (optional but required for AI features)

## Environment Variables
Create a `.env` file in the root directory (or in both `/backend` and `/frontend`). Use the provided `.env.example` as a template.

**Required Secrets:**
* `MONGODB_URI`: Your MongoDB connection string.
* `JWT_SECRET`: A secure random string for JWT signing.
* `GEMINI_API_KEY`: For the AI Coach features.

*Note: Never commit your `.env` files to version control.*

## Local Development

**1. Run the Backend**
```bash
cd backend
npm install
npm run dev
```

**2. Run the Frontend**
```bash
cd frontend
npm install
npm run dev
```

## Build
To build the frontend for production:
```bash
cd frontend
npm run build
```

## API Structure
The backend exposes a RESTful API under `/api`:
* `/api/auth` - Authentication & Registration
* `/api/users` - User Management
* `/api/memberships` - Membership Plans
* `/api/subscriptions` - Member Subscriptions
* `/api/trainers` - Trainer Profiles & Availability
* `/api/appointments` - Booking Sessions
* `/api/workouts` - Workout Plans & Logs
* `/api/exercises` - Exercise Dictionary
* `/api/attendance` - GPS & QR Check-ins
* `/api/progress` - Fitness Metrics & Goals
* `/api/notifications` - In-app Notifications
* `/api/reports` - Admin Analytics
* `/api/gemini` - AI Chat

## User Roles
* **Admin:** Full access to manage users, memberships, facility settings, and view reports.
* **Trainer:** Can manage assigned members, create workout plans, and set availability.
* **Member:** Can view their dashboard, log workouts, track progress, book trainers, and manage their subscription.

## Deployment Notes
* **Frontend:** The `dist` folder generated by `npm run build` can be deployed to Vercel, Netlify, or Cloudflare Pages.
* **Backend (Cloudflare Workers):** If deploying the Express backend to Cloudflare Workers, note that Cloudflare operates in a V8 isolate environment. You will need to adapt the standard Express server using a compatibility layer (like `itty-router` or Cloudflare's Express polyfills).
* **Cron Jobs:** The backend currently uses `node-cron` for scheduling tasks (like checking expired subscriptions). In a serverless/Cloudflare environment, `node-cron` cannot run continuously. You must convert these tasks to **Cloudflare Cron Triggers** (`wrangler.toml` schedules) that invoke a specific API endpoint or worker handler.
